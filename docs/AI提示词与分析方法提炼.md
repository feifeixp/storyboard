# AI 提示词与分析方法全流程提炼 (Visionary Storyboard Studio)

本文档提炼了系统中从原始剧本到最终输出 Seedance 2.0 视频生成提示词的完整 AI 工作流，包含了核心的提示词结构和数据分析方法。

## 1. 角色设计 (Character Design)
- **系统层定位**: \`prompts/extractCharactersPrompt.ts\`
- **核心任务**: 从剧本中识别所有角色，并推断生成专属的 AI 绘画外观描述，用于跨镜头维持角色一致性。
- **分析方法与规则**:
  1. **信息提取**: 识别所有有台词或有动作描述的核心角色（忽略群演等无具体设定的个体），并自动推断性别。
  2. **可视化强制翻译**: 将抽象描述转化为**纯可视化的外观设计指令**。长度至少 50 字。
  3. **必须包含的五要素**:
     - **发型发色**（e.g. 浅棕色碎短发、蓬松有层次感）
     - **面部特征**（e.g. 深棕色狭长眼眸、五官清爽利落、表情平静）
     - **身形体态**（e.g. 身形高挑纤瘦、少年感体态）
     - **服饰造型**（e.g. 纯白色圆领宽松T恤、黑白运动鞋）
     - **整体气质**（e.g. 日系动漫风格、清瘦修长）
  4. **负面约束**: 绝对禁止掺杂动作/剧情段落（如"声音沙哑，双手合十"），只描述静态立绘所需的硬层视觉信息。

---

## 2. 剧本优化与清洗 (Script Optimization & Cleaning)
- **系统层定位**: \`prompts/cleanScriptPrompt.ts\`
- **核心任务**: 以电影分镜师的视角，剥离文本中的无效信息，将剧情结构化为视觉与听觉层。
- **分析方法与规则**:
  1. **信息归类与清洗**:
     - **画面转化**: 角色动作与场景描述提取为“纯画面内容”。
     - **分离轨**: 对白单独提取为 \`dialogues\`，字幕/UI提取为 \`uiElements\`。
     - **情绪降维**: 物理的声音/BGM（如"滋滋声"或"低沉音乐"），须提炼为**情绪标签**（Mood Tags，如“紧张”、“恐惧”），并抛弃原始纯声音文字。
  2. **提取设定刚性约束**: 识别全局逻辑雷区。如剧本设定中带有“无物理杀伤力”，则转化为硬规则：禁止分镜中出现物体破碎或爆炸画面。
  3. **评估剧情权重 (Weight & Pacing)**:
     - **高权重 (High)**: 核心事件/高潮/转折点，切分为 3-5 个镜头。
     - **中权重 (Medium)**: 重要情节发展，切分为 2-3 个镜头。
     - **低权重 (Low)**: 铺垫/过渡区，切分为 1-2 个镜头。

## 3. 提示词提取与分镜设计 (Prompt Extraction & Shot Design)
- **系统层定位**: \`prompts/extractImagePromptsPrompt.ts\` & \`prompts/chain-of-thought/stage4-shot-design.ts\`
- **核心任务**: 提取用于 Nano Banana Pro (Gemini) 生图的精确视觉提示词，并将分镜维度的情绪绑定到摄像机参数上。
- **分析方法与规则**:
  1. **提示词公式**: \`[主体描述] + [环境/背景] + [动作/状态] + [技术参数(景别/角度/光影)]\`
  2. **双重术语转换**: 禁止在中文提示词里暴露分镜简写（如 CU, LS）或直接混用，必须换算成底层 AI 易懂的**摄影名词**（近距离拍摄、宽镜头拍摄等）。
  3. **情绪驱动相机机位**: 机位不再是随机的，而是依附于清洗阶段获得的 Mood Tags。
     - **压抑/孤岛感**: 中度俯拍 (15-45°)。
     - **气场/英雄登场**: 轻微仰拍 (5-15°)。
     - **精神错乱/追逐**: 必须掺杂荷兰角 (Dutch Angle)。
  4. **透视与形变对应**: 若指定了极限相机角度，必须附带说明对象的形变。
     - 仰拍 -> 描述“下巴突出，人物高耸”。
     - 俯拍 -> 描述“头顶突出，身体压缩”。
  5. **三大空间景深定律 (FG / MG / BG)**:
     - 必须明确【前景】、【中景主体】、【背景】。
     - **极重规避法则**: 前景提示词绝对不能提到“边框（frame/edge）”或使用方括号 \`[前景: xxx]\`，导致生成出物理画框！必须用自然语言如：“浅景深，画面底部有虚化的残片入画”。
  6. **角色引用体系**: 任何提到的主角名称强制打上 \`@角色名(子状态)\` 的 Tag，供系统后期寻址注入角色一致性遮罩或参考图。

## 4. 输出最终 Seedance 2.0 视频提示词 (Final Seedance 2.0 Output)
- **系统层定位**: \`src/utils/videoGrouping.ts\`
- **核心任务**: 将离散的图文分镜打组（每组 ≤ 15秒），合成最终能直接送到各类视频模型（尤其是 Seedance 2.0）的连续性长提示词。
- **分析方法与规则**:
  1. **素材首帧引流锁定**: 注入固定头部模板指令：\`以@图片x作为分镜参考，\`。配合前端生成的聚合大图作为视频运算起始基准。
  2. **风格/画质全局锁定**: 根据场景参数设定基调并强制添加“保持画面风格统一”后缀。
  3. **时间轴轨道铺设 (Timeline Scripting)**:
     循环遍历组内的所有镜头，翻译为由时间节点构成的动作序列（0-N秒）：
     - 运镜规范化映射（如将 \`Dolly In\` 翻译为 \`镜头缓慢推进\`）。
     - 同期声打轴（如注入 \`说话"原文对白"\` 和音效描述）。
  4. **动态转场推演 (Infer Transitions)**:
     引擎通过判断前后两帧的景别和场景差，自动预判并植入平滑转场词句：
     - 若跨 Scene -> 植入 \`无缝渐变转场，\`。
     - 远景切特写 -> 植入 \`快速推进特写，\`。
     - 特写切远景 -> 植入 \`镜头急速拉远，\`。
     - 同景别相切 -> 植入 \`切镜，\`。
  5. **全局运动结语**: 依据组内是否出现运动，在文末收尾（如“多镜头切换”、“全程xxx秒，一镜到底”）。

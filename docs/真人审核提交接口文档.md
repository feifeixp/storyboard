# 真人审核提交接口文档

## 接口概述

该接口用于提交图片到 Ark 平台进行真人审核。

接口会先根据 `imageUrl` 提取文件名（不含后缀）进行去重：

- 如果该文件名已存在审核记录，则直接返回已有审核记录状态，不会重复创建资产。
- 如果不存在，则会同步创建 Ark 资产并等待审核结果，成功后保存审核记录并返回。

## 接口信息

- **接口路径**: `/agent/ark-asset-review/submit`
- **请求方法**: `POST`
- **请求类型**: `application/json`
- **响应类型**: `application/json`

## 请求参数

### Headers

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| accessToken | String | 是 | 用户访问令牌 | `eyJhbGciOiJIUzUxMiJ9...` |

### 请求体 (ArkAssetReviewReq)

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| imageUrl | String | 是 | 待审核图片地址 | `https://example.com/image.jpg` |

### 请求示例

```bash
curl -X POST "http://localhost:8080/agent/ark-asset-review/submit" \
  -H "Content-Type: application/json" \
  -H "accessToken: your-access-token" \
  -d '{
    "imageUrl": "https://wlpaas.weilitech.cn/smart/dev/test/review-image.jpg"
  }'
```

```json
{
  "imageUrl": "https://wlpaas.weilitech.cn/smart/dev/test/review-image.jpg"
}
```

## 响应参数

### 响应体类型

`SingleResponse<ArkAssetReviewRes>`

### data 字段说明

| 参数名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| fileName | String | 文件名，不包含后缀 | `review-image` |
| imageUrl | String | 保存到系统中的图片路径，通常为去掉域名后的相对路径 | `smart/dev/test/review-image.jpg` |
| groupName | String | 分组名称 | `默认分组` |
| arkAssetId | String | Ark 平台资产 ID | `asset_123456789` |
| reviewStatus | Integer | 审核状态：`0-待审核`、`1-审核中`、`2-审核通过`、`3-审核失败` | `2` |
| reviewStatusDesc | String | 审核状态描述 | `审核通过` |
| taskStatus | Integer | 任务状态：`0-待处理`、`1-创建分组中`、`2-创建资产中`、`3-处理完成`、`4-失败` | `3` |
| errorMessage | String | 错误信息，成功时通常为空 | `null` |
| existed | Boolean | 是否命中已有记录，`true` 表示复用已有审核记录，`false` 表示本次新建 | `false` |

### 响应示例

```json
{
  "success": true,
  "data": {
    "fileName": "review-image",
    "imageUrl": "smart/dev/test/review-image.jpg",
    "groupName": "默认分组",
    "arkAssetId": "asset_123456789",
    "reviewStatus": 2,
    "reviewStatusDesc": "审核通过",
    "taskStatus": 3,
    "errorMessage": null,
    "existed": false
  },
  "errCode": null,
  "errMessage": null
}
```

## 业务逻辑说明

### 1. 登录态校验

- 从用户上下文中获取当前登录用户。
- 如果用户未登录，接口直接报错：`用户未登录`。

### 2. 企业权限校验

当配置项 `ark.asset.review.all-users-enabled=false` 时，会执行额外校验：

- 当前用户必须是企业用户。
- 用户必须绑定企业。
- 企业必须开通 `model_id=33` 的能力。

否则返回以下错误之一：

- `仅企业用户可使用真人审核功能`
- `当前企业未开通真人，请联系商务`

### 3. 文件名去重

- 服务会从 `imageUrl` 中提取文件名，并去掉扩展名。
- 根据 `fileName + delFlag=0` 查询是否已存在审核记录。
- 若存在，则直接返回已有记录，并将 `existed` 置为 `true`。

### 4. 新建审核记录流程

若不存在历史记录，则执行以下流程：

- 从分组表中获取默认分组名称。
- 确保 Ark 分组存在。
- 将图片路径转换为可访问的媒体 URL。
- 调用 Ark 资产创建接口创建图片资产。
- 以 **300ms** 间隔轮询，最长等待 **50 秒**，直到资产进入可用状态。
- 审核成功后保存数据库记录。

新建成功时，默认写入以下状态：

- `reviewStatus = 2`
- `taskStatus = 3`
- `retryCount = 0`
- `delFlag = 0`

### 5. 图片地址说明

该接口请求中的 `imageUrl` 可以是完整 URL。

保存到数据库并在响应中返回的 `imageUrl` 字段，会被转换为去除域名后的相对路径，例如：

- 请求值：`https://wlpaas.weilitech.cn/smart/dev/test/review-image.jpg`
- 返回值：`smart/dev/test/review-image.jpg`

## 状态说明

### reviewStatus

| 值 | 说明 |
|----|------|
| 0 | 待审核 |
| 1 | 审核中 |
| 2 | 审核通过 |
| 3 | 审核失败 |

### taskStatus

| 值 | 说明 |
|----|------|
| 0 | 待处理 |
| 1 | 创建分组中 |
| 2 | 创建资产中 |
| 3 | 处理完成 |
| 4 | 失败 |

## 错误码说明

| 错误信息 | 说明 | 解决方案 |
|----------|------|----------|
| 图片URL不能为空 | 请求参数 `imageUrl` 为空 | 检查请求体是否正确传参 |
| 用户未登录 | 用户上下文为空或令牌失效 | 重新登录并携带有效 `accessToken` |
| 仅企业用户可使用真人审核功能 | 当前用户不是企业用户，或未绑定企业 | 使用企业账号调用接口 |
| 当前企业未开通真人，请联系商务 | 企业未配置 `model_id=33` | 联系商务或管理员开通能力 |

## 注意事项

1. 接口按**文件名**去重，不按完整 URL 去重。即使 URL 不同，只要提取出的文件名相同，也会命中已有记录。
2. 该接口为**同步提交接口**，新建审核记录时会等待 Ark 资产审核结果返回，最长约 **50 秒**。
3. 如果命中已有记录，返回的 `reviewStatus`、`taskStatus`、`errorMessage` 为历史记录当前状态。
4. 返回的 `imageUrl` 为系统内部保存路径，不一定是原始请求时传入的完整 URL。
